# v0.1.0

- ASCII case-only and directory-prefix checks for branches and tags.
- Local Git, explicitly selected public HTTPS remote, and strict offline stdin modes.
- Value-free reports by default, opt-in escaped names, stable JSON status.
- UNKNOWN on failed queries or malformed input; no mutation or auto-repair.
- macOS/Linux tests, including byte-for-byte unchanged real local repository.

Not a Unicode/APFS simulator, custom-refspec validator or fetch guarantee.
